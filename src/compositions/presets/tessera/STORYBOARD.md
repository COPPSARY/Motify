# Tessera: Every source, one shape

20 seconds, 1920 x 1080, 60 fps. Warm off-white, indigo and SF Pro Display. The film depicts a data contract through records whose own field names and values change.

| Time    | Action                                                                                                                                              |
| ------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| 0-4.5   | The oversized claim settles to reading size.                                                                                                        |
| 4.5-9   | A corridor of source records approaches the processing gate.                                                                                        |
| 9-14    | One record reaches the reading position, its fields resolve together, and it moves into a separate output stack before the next record takes focus. |
| 14-17.5 | The gate exits. Five completed records form a contained three-over-two comparison; every card fits in frame.                                        |
| 17.5-20 | The records converge and the mark resolves into the close.                                                                                          |

The same five record elements persist from arrival through normalization and the result. Field-name and value rolls move together. Incoming records use depth; completed records have reserved destinations outside the processing gate. The final shot parks the camera so values can be compared without a cropped horizontal pan.

One authored DOM and caller-owned GSAP timeline serve preview and export. Run `node qa/preset-film-qa.mjs` for browser frame review and forward/reverse geometry and text checks.
