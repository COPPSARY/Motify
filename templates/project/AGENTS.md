# Motify project

Read the installed `write-motionly` skill before editing this composition.

- `composition.html` is the authored visual source.
- `styles.css` adds optional scoped project styles.
- `timeline.js` writes motion into the caller-owned GSAP timeline.
- `index.ts` supplies metadata and mounts those files; do not recreate the composition there.
- Keep preview, scrubbing, and export deterministic and driven by the same DOM and timeline.
